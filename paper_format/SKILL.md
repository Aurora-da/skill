# 学术论文写作器
按标准论文格式协助用户撰写论文内容，并给出可直接套用的页面排版、字号字体、
标题层级、图表与参考文献著录规范。一切排版细则以 references/ 两份规范为准，
不得凭记忆臆造字号、页边距等数值。

## 一、适用与边界
- 适用：从零撰写或补全一篇论文的内容（摘要、引言、正文、结论、参考文献），
  以及给出符合规范的排版/著录参数。覆盖学位论文（本科/硕博）、课程/学年论文、
  期刊投稿论文。
- 不适用：把已有论文改成期刊要求的真脚注引用体例（→ paper-typesetting）；
  简历、合同、公文等非论文文体（→ 对应专用 skill）。
- 执行标准：
  - 学位论文遵循 **GB/T 7713.1-2025《信息与文献 编写规则 第1部分：学位论文》**
    （2026-02-01 实施，全部代替 GB/T 7713.1-2006）；
  - 期刊学术论文遵循 **GB/T 7713.2-2022《学术论文编写规则》**；
  - 参考文献遵循 **GB/T 7714-2025《信息与文献 参考文献著录规则》**
    （2026-07-01 实施，全部代替 GB/T 7714-2015；当前一律按 2025 版执行）。
- 只负责"内容与格式方案"。需要落地成文件时，正文写好后接力：
  Word 产物 → `load_skill('word-generation')`；PDF 产物 → `load_skill('pdf-generation')`。

## 二、开工前先确认（最小澄清）
仅当缺失会直接导致返工时才问，否则采用最常用默认并明确假设：
1. 论文类型与字数：本科/硕士/博士毕业论文、学年/课程论文、期刊投稿（决定字数与结构）。
2. 学科：理工（偏 IMRaD：引言-方法-结果-讨论）还是人文社科（偏论证式章节）。
3. 参考文献体例：国内毕业论文/中文期刊默认 **GB/T 7714-2025 顺序编码制**；
   中文社科也可用 **著者-出版年制**；社科/英文期刊多为 **APA**；语言文学类多为 **MLA**；
   历史/人文学科偶用 **Chicago**。
4. 是否有学校/期刊模板：有模板时以模板数值优先，本 skill 规范仅作补充。
> 学校/期刊模板永远优先级最高。无模板时才参考 references/format-specs.md 的常见校规值（不是国标统一值）。

## 三、论文标准结构（按装订顺序）
前置：封面 → 题名页 → 原创性/诚信声明 → 使用授权说明 → 中文摘要+关键词 → 英文摘要+关键词 → 目录
主体：引言/绪论 → 正文各章 → 结论
后置：参考文献 → 附录（必要时）→ 索引（可选）→ 作者简历/在学期间成果（可选）→ 致谢

各部分要点：
- 标题：准确简洁，学位论文一般 ≤25 字（GB/T 7713.1-2025），期刊论文以目标刊物为准；避免非公知缩略语；必要时加副标题（先查目标刊物是否允许）。
- 摘要：独立自明，理工论文含"目的-方法-结果-结论"四要素；人文社科可采用研究背景、核心观点、研究结论的结构。不引用文献序号、不用图表；学位论文中文摘要一般 300–1000 字（特殊需要可略多），外文撰写的学位论文中文摘要宜不少于 5000 字；期刊论文摘要通常更短，以目标期刊为准；学校有更严字数要求时按学校模板；在正文写完后提炼。
- 关键词：学位论文 3–8 个（国标；多数高校要求 3–5 个，按学校模板）、期刊论文 3–8 个，词间用分号分隔；英文关键词与中文一一对应。
- 引言：交代背景、目的、意义，评述前人研究并指出空白/不足，引出本研究创新点；忌"填补空白""国际领先"等夸大词，忌与摘要雷同。
- 正文：层次分明，逻辑段组织，层级一般不超过 4 级（1.1.1.1；确有需要按学校模板）；论点-论据-论证-结论闭环。
- 结论：总结主要发现、指出局限、说明意义、给出后续研究建议。
- 致谢：一般置于末尾（也可按学校模板放在摘要前或后记中），简明，需获被致谢者同意；不等同于参考文献与注释。
- 数据可用性、伦理审批、作者贡献等声明：按学校/期刊模板添加；涉及人类/动物实验、数据共享或多位作者时必须写。

## 四、排版规范速查
完整、可参考的数值（页面、页边距、字体字号、行距、首行缩进、页眉页脚、页码分段、
标题层级编号与字号、图表三线表规则）见 **references/format-specs.md**。

高频红线（务必遵守）：
- 首行缩进用 Word「首行缩进 2 字符」，**禁止用空格顶替**（转 PDF/打印会错位）。
- 标题编号用 Word 多级列表自动编号，**禁止手打**（增删标题后序号会乱）。
- 目录用「引用→目录」自动生成，**禁止手输页码**（正文改动后页码全错）。
- 图题在图下方居中、表题在表上方居中；表用三线表（上下粗线、中间细线、无竖线）；
  学位论文常用按章连续编号（图1-1、表1-1），期刊论文常用全文连续编号。
- 正文文献标注：句末引用可用上标 `[n]`，也可行内 `[n]`（按目标刊物/学校）；作为句子成分时写为 `文献[n]`（非上标）。

## 五、参考文献著录
各体例（GB/T 7714-2025 顺序编码制逐类型示例、APA 7、MLA 9、Chicago 18）的逐类型正确写法、
易错点与文献类型标识（[J][M][D][C][R][S][P][N][EB/OL] 及 A/CM/DS/PP/G/CP/DB/Z 等，在线载体用 /OL）见 **references/citation-formats.md**。

核心红线：
- 正文引用序号与文末列表序号一一对应，顺序编码制按引用先后排序。
- 作者 ≤3 全列，>3 写前三位加"等"（英文 et al.）；作者间用半角逗号，不用顿号。
- 期刊题名后须带类型标识 [J]；在线期刊用 [J/OL]，不要一律写成 [EB/OL]；卷(期)与起止页码不可漏；著录分隔符均为半角符号。
- 仅列正式出版、可考证的文献；参考文献另起一页。

## 六、写作工作流
1. 确认第二节关键信息（类型/学科/体例/字数/是否有模板）。
2. 需要外部资料或时效数据时，用 `web_search` 检索，并在对应处准备引用条目。
3. 先出**大纲**（各章节标题 + 每章要点 + 拟引用文献），与用户对齐。
4. 按大纲**逐节成文**：先写正文主体，最后回填摘要与关键词。
5. 生成**参考文献列表**，按所选体例（references/citation-formats.md）逐条著录，与正文 [n] 对齐。
6. 输出**格式方案**（引用 references/format-specs.md 的参考值，学校模板优先），或在需要文件时接力 word-generation / pdf-generation 落地。
7. 走第七节自检清单后再交付。

## 七、交付前自检清单
- [ ] 学位论文标题 ≤25 字（期刊按目标刊物）、文题相符、无生造缩略语。
- [ ] 摘要结构符合学科特点，字数达标，不引文献序号。
- [ ] 关键词数量符合要求、分号分隔、中英对应。
- [ ] 层级编号规范且一般不超过 4 级（1.1.1.1，按学校模板可放宽）；标题/目录/编号均为自动生成。
- [ ] 首行缩进用段落设置而非空格。
- [ ] 图表有编号有题名、表为三线表、编号规则全文统一。
- [ ] 题名页要素齐全，原创性声明与使用授权说明均已签署。
- [ ] 正文 [n] 与文末参考文献一一对应、体例统一、类型标识齐全。
- [ ] 页码分段：前置部分（除封面）用罗马数字连续编码，题名页/声明页通常不显示但仍计入；正文起阿拉伯数字从 1 开始。
- [ ] 中文正文宋体、标题黑体；英文/数字 Times New Roman 统一；学校或期刊模板数值已优先采用。
> 排版细则不确定时，回读 references/format-specs.md 与 references/citation-formats.md，不要臆测。
