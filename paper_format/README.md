# paper-writing skill
学术论文写作 skill。输入论文主题与要求，输出符合规范论文内容与格式方案；
需要文件时接力 word-generation / pdf-generation 落地。

## 目录结构
- SKILL.md —— 主指令（结构、工作流、自检清单）
- references/format-specs.md —— 页面/字号/行距/标题/图表排版规范速查
- references/citation-formats.md —— GB/T 7714 / APA / MLA / Chicago 著录规范

## 执行标准
- 学位论文：GB/T 7713.1-2025《信息与文献 编写规则 第1部分：学位论文》（2026-02-01 实施）
- 期刊论文：GB/T 7713.2-2022《学术论文编写规则》
- 参考文献：GB/T 7714-2025《信息与文献 参考文献著录规则》（2026-07-01 实施，全部代替 GB/T 7714-2015）
- 排版数值：references/format-specs.md 为常见校规参考值，不是国标统一值；学校/期刊模板优先。

## 安装
将整个 paper-writing 目录放入 skills 安装目录即可被识别加载。
